- Added typed theme registry, variants, and sizes.
- Added progress lifecycle, spinner/content transitions, placeholder shimmer,
  text transitions, size transitions, and SwiftUI-parity release spring behavior.
- Added Android demo app with themed, progress, social, and size-change screens.
